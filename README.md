from a 10-year automotive engineering background into Technical Business 
Analysis.

Demonstrates core BA fundamentals — requirement gathering, stakeholder

requirements documentation, using a business process transformation example.

**Skills demonstrated:** Stakeholder analysis, functional/non-functional 
requirements, process mapping, acceptance criteria

### 2. Technical BRD

This pairing reflects my transition path — solid foundational BA skills,
